# Contributing and reporting issues

Use [GitHub Issues](https://github.com/Dorking643/caisson-rebar-revit/issues) for reproducible problems or feature proposals. CaissonRebar is licensed under [Apache-2.0](LICENSE); see [AUTHORS.md](AUTHORS.md) and [license scope](docs/LICENSING.md).

Unless explicitly stated otherwise, contributions intentionally submitted for inclusion are under Apache-2.0, as provided by Section 5 of the license. Preserve existing attribution and describe changes clearly.

For a bug report, include:

1. The add-in version and Revit version/build.
2. Whether the wall, slab or combined sample was used.
3. The shortest steps that reproduce the issue.
4. Expected and observed behavior, with an anonymized screenshot if helpful.

Use a small anonymized model or the included shell examples when possible. Remove personal paths, project names and unrelated model contents from logs and images before attaching them.

For a proposed change, describe the behavior being changed and its validation. Keep unrelated geometry or interface changes separate. Run the local checks described in [BUILD.md](docs/BUILD.md). Changes that require a live Revit session should state which Revit steps were actually exercised.
