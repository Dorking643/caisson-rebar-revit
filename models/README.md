# 井壁与底板脱敏空壳模型

本目录提供不含钢筋的混凝土井壁、底板示例模型，用作钢筋建模的起点。三份模型均已保存并重新打开核验。

## 文件与内容

| 文件 | 混凝土宿主 | 实测实体构件数量 | 实测钢筋数量 |
|---|---|---:|---:|
| `Wall.rvt` | 井壁 | 1 | 0 |
| `Slab.rvt` | 底板 | 1 | 0 |
| `Combined.rvt` | 井壁及底板 | 2 | 0 |

模型使用 Autodesk Revit 2025。查看模型本身不需要插件；设置参数并生成钢筋时，需要安装本包对应插件。

每份模型包含 `01_Concrete_Shell` 三维视图及 `02_Concrete_Shell_Plan` 俯视三维视图。井壁宿主保留技术标记 `CJ-WALL`，底板宿主保留 `CJ-SLAB`，供插件识别；请勿随意修改这两个标记。

井壁读取尺寸为内半径 2250 mm、外半径 2700 mm、高度 5480 mm；底板读取外半径 2400 mm、主厚度 400 mm。完整截面以模型实际几何为准。

## 开始建模

1. 将压缩包完整解压，按 `../installer` 的 README 安装插件。
2. 复制一份目标 RVT 用作工作文件，然后在 Revit 2025 中打开。
3. 进入 `Caisson Reinforcement > Model Creation > Wall` 或 `Slab`，读取当前文档并选择对应混凝土宿主。在组合模型中确认宿主类型正确。
4. 核对宿主尺寸、局部坐标与标高，按自己的建模要求设置钢筋形状、直径及布置参数。
5. 检查预览后生成钢筋，核对实际结果并另存工作文件。

本目录没有已有钢筋或旧配筋参数存储；钢筋输入条件由使用者确定。生成结果应按实际用途另行检查。

## 脱敏与核验结果

模型仅保留所需混凝土宿主和建模所需的基本定义。原工程文件未改动。

- 三份模型的钢筋数量均为 0，实体构件数量分别为 1、1、2；没有额外实体场景构件。
- 井壁和底板均通过插件宿主读取器检查。实体几何指纹与保留来源一致，独立模型与组合模型中的对应宿主指纹也一致。
- `DataStorage` 和有效扩展存储实体数量均为 0。
- 项目作者和场地名称为空，场地经纬度已置为 0；保存文件的用户名和中心文件路径为空。
- API 可见名称、字符串参数及可读文件字符串的已知身份标识检查无命中。
- 已绑定的外部文件引用为 0。Revit 保留两个无路径的默认表占位项，分别为关键注释表和装配代码表，不指向外部文件。
- 三份最终 RVT 的 SHA-256 均与随包记录一致。

详细结果见 `../verification/models/Wall_model_verification.json`、`Slab_model_verification.json` 和 `Combined_model_verification.json`。
