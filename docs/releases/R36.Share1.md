# CaissonRebar v36.1.0 — release-note draft

Software: **CaissonRebar — Parametric Reinforcement Modeling for Circular Caissons**. Project version: **36.1.0** (R36.Share1). Intended Git tag: **v36.1.0**. The software publication date is **2026-10-29**; the GitHub Release status is determined by the published release page.

## Included

- Source code for the Revit 2025 wall and slab reinforcement add-in.
- Per-user Windows installer and uninstaller with payload checksums.
- Three anonymized concrete shell models: Wall, Slab and Combined; all contain zero reinforcement bars.
- English/Chinese introductions, usage and build documentation, repository templates and recorded checks.

## Changes in this distribution

- Runtime logs and drafts use the current user's local application data directory.
- Revit API build dependencies are resolved from a configurable local installation path.
- Original project-specific default reinforcement parameters are not automatically loaded.
- Source and documentation have been arranged for a GitHub repository. The prepared DLL and RVT files retain the hashes of the verified distribution.

## Use

Download and extract the complete repository/distribution ZIP. Close Revit, run `installer/Install.bat`, restart Revit 2025 and open a working copy of a model under `models`.
